# useMarket Landing Page

Public landing page for useMarket — a local-commerce marketplace connecting customers, vendors and riders.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The page includes the official useMarket logo, responsive layout, WhatsApp and voice-ordering sections, customer/vendor/rider positioning, launch cities and a waitlist call to action.
